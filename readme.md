# 🚗 ANPR Gate System

AI-based Automatic Number Plate Recognition system.

## Features
- Real-time plate detection (YOLO)
- OCR (EasyOCR)
- Entry / Exit tracking
- Vehicle type detection (car, truck, bus)
- Alert system (7 entries in 1 hour)
- Streamlit UI

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
